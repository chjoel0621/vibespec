# 0.18.0 릴리스 검증 기록

기준일: 2026-09-15. 상태: 필수 검증 완료, 0.18.0 게시 대상.
게시 상태와 최종 커밋은 [0.18.0 릴리스](https://github.com/chjoel0621/vibespec/releases/tag/v0.18.0)에서 확인한다.

## 범위와 호환성

- 최신 main의 IT 기획 템플릿 추가와 이번 변경을 별도 릴리스 브랜치에서 통합했다.
- 선택적 lifecycle journal, 목적별 내용 검토, 오래된 KPI 검사 표시, 평가 집계와 회귀 검증을 포함한다.
- SOT 1.0/1.1 형식은 유지한다. 기존 제품 폴더를 자동 등록하거나 이전하지 않는다.
- 변경 이력 기능은 opt-in 초기 기능이다. 기획 승인, 서비스 코드 자동 동기화, 사람 검토 완료, 전체 파일 원자성이나 전원 장애 내구성을 보장하지 않는다.
- 사용 방법과 복구 경계는 [변경 이력 안내](../lifecycle-journal.md), 릴리스 절차는 [배포 안내](../releasing.md)를 따른다.

## 문서와 공개 범위

이전 실패 기록은 [논리 결함 수정](2026-09-15-lifecycle-logic-fix.md)과
[경로·부모 누락 수정](2026-09-15-lifecycle-path-parent-resilience.md)에 그대로 보존한다.
CHANGELOG는 필수 검증을 통과한 게시 절차에서 0.18.0으로 확정했으며 누락됐던 0.17.2 항목은 기존 공개 릴리스에 근거해 보완했다.

공개 후보에는 소스, 사용·설계 문서 및 합성 감사 JSON만 포함한다. 실제 서비스 분석 산출물,
로컬 호스트 로그·생성 기획, 설치 캐시와 무관한 기존 데모 문서 수정은 포함하지 않는다.
문서에서 언급하는 로컬 검토 패킷은 공개 저장소에 없으며 해당 평가 명령으로 별도 재생성할 수 있다.
호스트 증거는 설치된 검증기가 생성한 이식 가능한 JSON만 원문 그대로 커밋한다.

## 실제 호스트 실행 기록

후보 PR [#14](https://github.com/chjoel0621/vibespec/pull/14)는 CI 통과 후 main에 병합됐다.
병합 커밋은 `d4e5b9316bfe6edc84f4ff9b27bf2ce7e116420e`이며,
[main CI](https://github.com/chjoel0621/vibespec/actions/runs/34935787111)와
[데모 Pages 배포](https://github.com/chjoel0621/vibespec/actions/runs/34935787137)도 통과했다.

처음 Claude 실행에서는 출력 대기와 이전 사용자 설치본의 우선 로드를 확인해
해당 세션을 중단했다. 이전 설치본 결과는 증거로 채택하지 않았다. 사용자 설치본을
0.18.0으로 갱신하고 저장소 밖 새 작업 폴더에서 실제 로드 경로·버전을 확인한 뒤
독립 생성했다. 처음 작성된 상세기능 참조의 인덱스와 IA 누락은 호스트가 검증기
오류를 보고 수정했으며 최종 검증과 JSON/HTML 일치 검사를 통과했다.

Codex CLI 0.147.0은 기존 기본 모델을 지원하지 않아 API 요청이 거절됐다.
[공식 CLI 안내](https://learn.chatgpt.com/docs/codex/cli)를 확인하고 별도 검증용
폴더에 공식 CLI 0.154.0을 설치했다. 기존 앱 바이너리와 기본 모델 설정은 변경하지 않았다.
양쪽 호스트 모두 권한 검사 우회 옵션은 사용하지 않았다. 설치 경로·원시 로그·
실제 생성 기획은 공개 증거에서 제외한다.

최종 Claude 실행은 Claude Opus 4.7, Codex 실행은 기존 기본 모델인 GPT-6 Astra를 사용했다.
서로 다른 새 폴더·세션에서 독립 작성했으며, 생성된 SOT와 HTML 해시도 서로 다르다.
두 결과 모두 구조 검증·내용 리뷰·측정 검사·호스트 검증을 통과했고, 사람의 정책 승인 결정은 열려 있다.
생성 품질 비교나 통계적 우열을 판정하기 위한 실험이 아니다.

검증기가 생성한 원본 기록:
[Claude Code](../../acceptance/hosts/v0.18.0/claude-code.json),
[Codex CLI](../../acceptance/hosts/v0.18.0/codex-cli.json).
증거만 반영한 커밋은 `9889cc81cadc6f6288782217a28ec7c5b95483c4`다.
이후 변경은 이 배포 기록·사용 안내·CHANGELOG 정리에만 한정한다.

## 게시 조건

최종 후보의 canonical runtime-bundle SHA-256:
`3926cd8a4c83e7b10473af0406d545c9904c02cce92eaf3212922aa43f4b3d8e`.

두 호스트의 버전·런타임 digest가 최종 후보와 일치하고 로컬·원격 게이트가 모두 통과하기 전에는 태그나 릴리스를 게시하지 않는다.
